# 🎬 Фільми та серіали — Movie Ratings App

Рейтинг фільмів та серіалів від Анастасії та Дмитра.  
Працює повністю на **GitHub Pages** — без серверів, без баз даних.  
Дані зберігаються у файлі `data.json` у репозиторії через GitHub API.

---

## 🚀 Швидке налаштування (5 хвилин)

### 1. Створіть GitHub репозиторій

1. Перейдіть на [github.com/new](https://github.com/new)
2. Створіть **новий публічний репозиторій** (наприклад, `movie-ratings`)
3. **Додайте файл README**
4. Скопіюйте всі файли з цього проєкту у репозиторій (або завантажте як ZIP)

### 2. Створіть Personal Access Token

1. Перейдіть на [github.com/settings/tokens/new](https://github.com/settings/tokens/new)
2. В полі **Note** напишіть: `Movie Ratings App`
3. В полі **Expiration** оберіть: `No expiration` (або бажаний термін)
4. **Обов'язково** поставте галочку на **`repo`** (Full control of private repositories)
5. Натисніть **Generate token**
6. **Скопіюйте token** (видасться лише один раз!)

> ⚠️ Поділіться цим токеном з другом — обидва зможуть редагувати.

### 3. Увімкніть GitHub Pages

1. Відкрийте репозиторій на GitHub
2. Перейдіть до **Settings** → **Pages**
3. В полі **Source** оберіть: **Deploy from a branch**
4. Оберіть гілку **main** і папку **/ (root)**
5. Натисніть **Save**
6. Через 1-2 хвилини ваш сайт буде доступний за адресою:
   `https://<your-username>.github.io/<repo-name>/`

### 4. Відкрийте сайт і налаштуйте

1. Відкрийте сайт у браузері
2. Ви побачите екран налаштування
3. Введіть:
   - **GitHub Username / Org** — ваш username на GitHub
   - **Repository Name** — назва репозиторію (наприклад, `movie-ratings`)
   - **Personal Access Token** — токен з кроку 2
4. Натисніть **Зберегти та Підключити**

Готово! 🎉

## 🔧 Як це працює

| Дія | Як реалізовано |
|-----|----------------|
| **Читання даних** | GitHub API → GET `data.json` з репозиторію |
| **Додавання фільму** | Оновлює `data.json` → GitHub API → PUT з новим комітом |
| **Редагування** | Оновлює `data.json` → GitHub API → PUT з комітом |
| **Видалення** | Оновлює `data.json` → GitHub API → PUT з комітом |
| **Синхронізація** | Кожен прихід на сторінку завантажує свіжі дані з GitHub |

Кожна зміна створює git commit у репозиторії — ви можете бачити повну історію змін!

## ⚠️ Обмеження

- **GitHub API Rate Limit**: ~5000 запитів/годину з токеном — цього більш ніж достатньо
- **Токен**: зберігається лише в `localStorage` вашого браузера
- **Час оновлення**: після зміни на одному пристрої, на іншому потрібно оновити сторінку (F5)
- **Конфлікти**: якщо двоє змінять дані одночасно, останній збережений виграє

---

## 🔑 Безпека

- Токен зберігається **тільки в браузері** (`localStorage`) — не відправляється нікуди, окрім GitHub API
- Репозиторій публічний — будь-хто може **читати** дані
- **Тільки володар токена** може **редагувати** дані
- Якщо токен скомпрометовано — видаліть його на [github.com/settings/tokens](https://github.com/settings/tokens) і створіть новий
